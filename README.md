# Tetris for KOReader

Install: copy the `tetris.koplugin` folder into KOReader's `plugins/` directory
(e.g. `koreader/plugins/tetris.koplugin`), restart KOReader, then open
**Top menu → ⚙/Tools (More tools) → Tetris**.

Controls
- Buttons: Left / Rotate / Right / Down (soft drop) / Drop (hard drop) / Pause
- On the board: tap = rotate, swipe left/right = move, swipe down = hard drop, swipe up = rotate
- Keys (if your device has them): d-pad moves/rotates/drops, page-turn buttons = down / rotate, Back = exit
- A hollow outline shows where the piece will land. High score is saved in `settings/tetris.lua`.
